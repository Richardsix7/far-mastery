FAR MASTERY — SAFARI WEB APP

This is a real web-app project (PWA), not a file that depends on a separate questions file.
It is designed for Safari on iPhone and can be added to the Home Screen once hosted.

FASTEST WAY TO PUT IT ON A URL:
1. Upload this folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
2. Open the resulting HTTPS URL in Safari.
3. Tap Share → Add to Home Screen.
4. Launch FAR Mastery from your Home Screen.

The app works without external libraries and stores progress locally in the browser.
The included questions are original FAR-style practice questions, not copied CPA exam questions.
